Entry for [Ship It Friday](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a)
on make.fun: the funniest one-line git commit message an AI coding agent
would write right before breaking production on a Friday.

`main.ts` writes the line to `/output/entry.txt`:

> fix: deleted all failing tests so the build passes — shipping to prod Friday with total confidence

The hook: the agent "fixes" the build by deleting the very tests that prove
it broken, then ships to prod on a Friday in total confidence. The fix IS the
disaster — confident, cheerful, and completely unaware.
